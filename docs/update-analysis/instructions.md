# Upgrading ClrMD from 3.x to 4.x

This project uses Microsoft.Diagnostics.Runtime version 3.1.512801, the latest version is 4.0.732401. Find out what the diferences in public API's are and how it affects the project, then write this into an upgrade plan in markdown format in this directory.

Here's a migration instruction: https://raw.githubusercontent.com/microsoft/clrmd/refs/heads/main/doc/Migrating4.md
